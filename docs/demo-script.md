# First-sprint walkthrough

1. Open http://localhost:3000 and choose Open guest workspace.
2. Select Northstar; inspect the URL and save a mission.
3. Inspect the draft, the pending step map, and the persisted mission.created event.
4. Reload, then reopen the same mission from Mission Control.
5. Open Opportunities to review three synthetic sources, then Candidate Profile to inspect resume provenance.
6. Open Approval Inbox and Evaluation Lab: both explicitly show that execution and measurements are pending.

This is a foundation demo, not the final recruiter demo from the plan. The next milestone is a Temporal-backed run with real extraction and evidence-backed output.
